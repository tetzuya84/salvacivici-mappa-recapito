# SalvaCivici – Mappa Recapito

Prototipo beta per iPhone: raccolta locale di civici e coordinate GPS.

## Stato

Questo repository contiene esclusivamente il codice dell'app. I civici rilevati restano nel database locale del dispositivo e non sono inviati al repository.

**Importante:** fare regolarmente un backup JSON. Non usare durante il recapito prima della prova GPS e della verifica del salvataggio su iPhone.
